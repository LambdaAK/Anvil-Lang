Autodiff · Native · Vectorized · Index Language

Anvil is a small language for machine learning. You write tensors, index notation and a loss. The compiler differentiates the whole training program, fuses it, and forges it into multithreaded ARM64 assembly, the Apple GPU, or CUDA. Every shape is known before the program runs, and every dimension knows its name.

The cost of one step
Microseconds per training step on one thread. The arithmetic of a softmax-regression step takes 22 µs; the rest of PyTorch's time is per-operation overhead.

Single operations from Python
One call at a time leaves nothing to fuse, so the CPUs are close: Anvil is 1.33× PyTorch eager on average. The GPU wins anything large.

      

      

    


    

      
Where PyTorch winsConvolutions on the GPU: Apple's tuned kernels behind MPS are 5× Anvil's Metal backend on the larger CNN. Fused attention, 2.8× on one call. Batch-1 calls from Python, 5.7 µs against 14.8.

      
Why Anvil is fasterThe whole training loop is compiled ahead of time: no interpreter between operations, no autograd graph, no allocation. The optimizer update is fused into the gradient kernels.

      
How it was measuredTraining time only, data loading and evaluation left out, GPU work included. Other programs used about 2 of 16 cores. The full method and every run: REPORT.md.

    

  






  

    

      Inside the compiler
      
From index notation to registers.

      
The compiler is about 15,000 lines of Python with no dependencies, plus a runtime written in assembly. The standard library (layers, losses, optimizers) is written in Anvil.

    

    

      
parse
Source
Python-like syntax with index notation, models, ~ normal(…) and minimize … with adam().

      
elaborate
Shapes & names
A staging interpreter runs the compile-time part, checks every shape and dimension name, and emits kernels.

      
autodiff
Gradients
Reverse mode on the kernel IR, at compile time. The backward pass is just more kernels to optimize.

      
optimize
Fusion
Elementwise work, reductions and the optimizer update are fused; temporaries share a static memory arena.

      
codegen
Backends
  • ARM64 NEON, register-tiled, multithreaded
  • Matrix products on the AMX unit
  • Apple GPU (Metal)
  • CUDA, one .cu file
  • A NumPy reference interpreter
